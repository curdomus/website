# curdomus website

Statische Website von Curdomus, ausgeliefert über GitHub Pages.

## Struktur

- `index.html` – Startseite
- `styles.css` – Styles
- `favicon.svg` – Favicon
- `assets/curdomus-logo.svg` – Logo mit Schriftzug (Querformat)
- `assets/curdomus-mark.svg` – Bildmarke allein (quadratisch)
- `.nojekyll` – deaktiviert die Jekyll-Verarbeitung auf GitHub Pages
- `CNAME` – Custom Domain für GitHub Pages

## Lokal ansehen

```bash
python3 -m http.server 8000
```

Danach http://localhost:8000 öffnen.
